# in-app-usage-guide Specification

## Purpose

설정에서 접근하는 플랫폼 맞춤형 앱 사용 안내의 탐색, 내용 범위, 오프라인 제공 및 접근성 동작을 정의한다.
## Requirements
### Requirement: 설정에서 앱 사용법 열기
iOS와 macOS 앱은 설정에서 식별 가능한 `앱 사용법` 진입점을 제공하고, 사용자가 이를 선택하면 설정 navigation 안에서 전용 사용 안내 화면을 열어야 한다(MUST).

#### Scenario: 설정에서 사용법 진입
- **WHEN** 사용자가 설정의 `앱 사용법` 항목을 선택한다
- **THEN** 시스템은 `앱 사용법` 제목과 기능별 안내를 가진 화면을 표시한다

#### Scenario: 사용법에서 설정으로 돌아가기
- **WHEN** 사용자가 앱 사용법 화면에서 뒤로 이동한다
- **THEN** 시스템은 설정 화면으로 돌아가며 기존 설정 상태를 유지한다

### Requirement: 핵심 기능의 행동 중심 안내
앱 사용법은 기록 생성과 편집, 다섯 가지 기록 유형, 태그와 분류, 검색, 휴지통, 동기화 및 앱 잠금의 핵심 사용 흐름을 기능별로 구분해 설명해야 한다(MUST). 안내 문구는 사용자가 해당 기능을 어디에서 시작하고 주요 결과가 무엇인지 이해할 수 있어야 한다(MUST). 휴지통 안내는 복원뿐 아니라 영구 삭제와 휴지통 비우기가 되돌릴 수 없다는 점도 포함해야 한다(MUST).

#### Scenario: 공통 기능 안내 확인
- **WHEN** 사용자가 iOS 또는 macOS에서 앱 사용법 화면을 연다
- **THEN** 시스템은 기록 작성·편집, 분류·검색, 삭제·복원, 동기화 및 앱 잠금에 대한 안내를 기능별 제목과 함께 표시한다

#### Scenario: 데이터 보호 경계 확인
- **WHEN** 사용자가 앱 잠금 안내를 읽는다
- **THEN** 시스템은 앱 잠금이 화면 접근을 보호하는 기기별 기능이며 데이터 자체를 별도 암호화하는 기능은 아님을 알린다

#### Scenario: 휴지통 영구 삭제 안내 확인
- **WHEN** 사용자가 휴지통 안내를 읽는다
- **THEN** 시스템은 복원 방법과 함께 개별 영구 삭제, 휴지통 비우기, 그리고 그 동작이 되돌릴 수 없다는 사실을 알린다

### Requirement: 플랫폼에 맞는 데이터 관리 안내
앱 사용법은 현재 플랫폼에서 실제 제공되는 데이터 관리 동작만 실행 가능한 기능으로 안내해야 한다(MUST). macOS에서는 Day One 가져오기와 백업·복원 사용법을 제공하고, iOS에서는 해당 동작을 iOS에서 실행할 수 있는 것처럼 표시해서는 안 된다(MUST NOT).

#### Scenario: Mac 데이터 관리 안내
- **WHEN** 사용자가 macOS에서 앱 사용법 화면을 연다
- **THEN** 시스템은 설정에서 Day One 가져오기와 전체 백업·복원을 사용하는 방법을 표시한다

#### Scenario: iPhone 데이터 관리 안내
- **WHEN** 사용자가 iOS에서 앱 사용법 화면을 연다
- **THEN** 시스템은 Day One 가져오기와 전체 백업·복원을 iOS에서 사용할 수 있는 설정 동작으로 표시하지 않는다

### Requirement: 오프라인 및 접근 가능한 안내
앱 사용법의 모든 필수 콘텐츠는 앱과 함께 제공되어 네트워크 연결 없이 표시되어야 하며(MUST), 시스템 동적 글자 크기와 VoiceOver에서 내용과 정보 계층을 읽을 수 있어야 한다(MUST).

#### Scenario: 오프라인에서 사용법 열기
- **WHEN** 기기가 네트워크에 연결되지 않은 상태에서 사용자가 앱 사용법을 연다
- **THEN** 시스템은 외부 페이지 로드나 오류 없이 모든 필수 안내를 표시한다

#### Scenario: 큰 글자 크기로 사용법 읽기
- **WHEN** 사용자가 접근성 글자 크기를 적용한 상태에서 앱 사용법을 연다
- **THEN** 시스템은 제목과 본문을 잘라내지 않고 줄바꿈 가능한 시스템 글꼴로 표시한다

#### Scenario: VoiceOver로 안내 탐색
- **WHEN** 사용자가 VoiceOver로 앱 사용법 화면을 탐색한다
- **THEN** 시스템은 기능별 제목과 관련 본문을 의미 있는 읽기 순서로 제공하고 색상만으로 의미를 전달하지 않는다
