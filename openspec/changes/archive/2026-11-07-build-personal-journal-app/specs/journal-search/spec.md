## ADDED Requirements

### Requirement: 기기 로컬 전체 텍스트 검색
macOS와 iPhone 앱은 제목, 본문, 태그 및 검색 가능한 유형별 상세 정보를 기기 로컬 인덱스에서 한국어로 검색해야 한다(MUST).

#### Scenario: 한국어 본문 검색
- **WHEN** 사용자가 본문에 존재하는 한국어 검색어를 입력한다
- **THEN** 시스템은 네트워크 연결 없이 해당 검색어가 포함된 로컬 기록을 결과에 표시한다

#### Scenario: 유형별 상세 정보 검색
- **WHEN** 사용자가 독서노트의 책 제목 또는 성경공부의 구절 표기에 포함된 검색어를 입력한다
- **THEN** 시스템은 일치하는 기록을 결과에 표시한다

#### Scenario: 결과가 없는 검색
- **WHEN** 어떤 기록에도 일치하지 않는 검색어를 입력한다
- **THEN** 시스템은 빈 결과 상태와 검색 조건을 지우는 동작을 표시한다

### Requirement: 검색 필터 조합
두 앱은 검색어와 기록 유형, 태그, 시작일, 종료일 필터를 함께 적용할 수 있게 해야 한다(MUST).

#### Scenario: 유형과 기간 조합
- **WHEN** 사용자가 `성경공부` 유형과 시작일·종료일을 선택한다
- **THEN** 시스템은 원래 현지 기록 날짜가 기간 안에 있는 성경공부 기록만 표시한다

#### Scenario: 여러 조건 조합
- **WHEN** 사용자가 검색어, 기록 유형 및 태그를 함께 지정한다
- **THEN** 시스템은 모든 지정 조건을 동시에 만족하는 기록만 표시한다

#### Scenario: 필터 초기화
- **WHEN** 사용자가 검색 조건 초기화를 선택한다
- **THEN** 시스템은 검색어와 모든 필터를 제거하고 기본 타임라인을 표시한다

### Requirement: 타임라인 탐색
두 앱은 기록을 원래 현지 기록 날짜 기준 최신순으로 탐색하게 하고 결과를 점진적으로 불러와야 한다(MUST).

#### Scenario: 기본 타임라인
- **WHEN** 사용자가 앱의 기본 기록 화면을 연다
- **THEN** 시스템은 로컬에 도착한 휴지통 이외 기록을 원래 현지 기록 날짜 기준 최신순으로 표시한다

#### Scenario: 다음 결과 불러오기
- **WHEN** 사용자가 현재 표시 범위를 지나 더 오래된 기록으로 이동한다
- **THEN** 시스템은 기존 순서를 유지하면서 다음 결과 묶음을 불러온다

### Requirement: 로컬과 원격 변경 색인
시스템은 로컬 저장과 CloudKit에서 수신한 변경을 기기별 검색 인덱스에 반영해야 한다(MUST).

#### Scenario: 로컬 수정 직후 검색
- **WHEN** 사용자가 기록 본문에 새 검색어를 추가해 저장한 뒤 검색한다
- **THEN** 시스템은 원격 동기화를 기다리지 않고 수정된 기록을 결과에 표시한다

#### Scenario: 원격 기록 수신
- **WHEN** iPhone이 Mac에서 생성하거나 가져온 기록을 CloudKit으로 수신한다
- **THEN** 시스템은 해당 기록을 로컬 인덱스에 추가한 뒤 검색 결과에 표시한다

#### Scenario: 휴지통 기록 검색
- **WHEN** 검색어가 휴지통의 기록에만 존재한다
- **THEN** 시스템은 일반 검색 결과에 해당 기록을 표시하지 않는다

### Requirement: 검색 인덱스 재구축
시스템은 검색 인덱스가 없거나 손상되거나 schema version이 바뀌면 canonical 로컬 데이터에서 재구축해야 한다(MUST).

#### Scenario: 인덱스 손상
- **WHEN** 앱 시작 시 검색 인덱스 무결성 또는 history token 불일치를 감지한다
- **THEN** 시스템은 canonical 기록을 변경하지 않고 인덱스를 재구축하며 진행 상태를 표시한다

#### Scenario: 재구축 중 검색
- **WHEN** 사용자가 인덱스 재구축 중 검색을 시도한다
- **THEN** 시스템은 준비된 범위의 결과 또는 제한된 fallback 검색을 제공하고 재구축 상태를 표시한다
