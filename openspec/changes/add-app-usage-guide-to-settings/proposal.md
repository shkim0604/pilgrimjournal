## Why

현재 앱의 주요 기능과 데이터 관리 방법은 저장소의 사용자 가이드에만 정리되어 있어, 사용자가 앱 안에서 필요한 사용법을 바로 찾기 어렵다. 설정에서 접근 가능한 앱 내 사용 안내를 제공해 기록 작성부터 동기화·백업까지의 핵심 흐름을 스스로 확인할 수 있게 한다.

## What Changes

- iOS와 macOS 설정에 `앱 사용법` 진입점을 추가한다.
- 앱 안에 기능별로 구분된 사용 안내 화면을 제공한다.
- 기록 작성·편집, 유형과 정리, 검색과 휴지통, 동기화, 앱 잠금 등 공통 사용 흐름을 설명한다.
- Day One 가져오기와 백업·복원처럼 플랫폼에 따라 제공 여부가 다른 기능은 현재 플랫폼에서 실제 사용할 수 있는 범위에 맞춰 안내한다.
- 안내는 네트워크 연결 없이도 읽을 수 있고, VoiceOver와 동적 글자 크기를 포함한 시스템 접근성 동작을 따른다.

## Capabilities

### New Capabilities

- `in-app-usage-guide`: 설정에서 접근하는 플랫폼 맞춤형 앱 사용 안내의 탐색, 내용 범위, 오프라인 제공 및 접근성 동작을 정의한다.

### Modified Capabilities

- 없음.

## Impact

- `Sources/PilgrimJournal/SettingsAndImportViews.swift`의 설정 정보 구조와 navigation이 변경된다.
- 앱 내 사용 안내를 표현할 새 SwiftUI view와 정적 안내 콘텐츠가 추가된다.
- iOS·macOS 설정 navigation, 플랫폼별 안내 노출, 접근성 및 콘텐츠 회귀 테스트가 추가된다.
- 외부 API, 네트워크 서비스, 데이터 모델 및 저장 형식에는 영향이 없다.
