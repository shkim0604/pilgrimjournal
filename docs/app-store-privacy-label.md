# App Store 개인정보 라벨 (그룹을 켜는 버전부터)

App Store Connect › 앱 › 앱 개인정보 보호에 넣을 값이다. 근거는 `docs/privacy.md` "그룹 서버"이고, 처리방침
URL은 지원 페이지(`SupportLinks.supportPage`) 그대로 둔다. 라벨은 버전별이 아니라 앱 전체에 붙고 게시하는 즉시
제품 페이지에 보이므로, 그룹을 켜는 빌드를 심사에 내는 날 게시한다(그때부터 기존 버전 페이지에도 이 라벨이 보인다).
같은 날 연령 등급 질문지도 다시 답한다(사용자 콘텐츠, 사용자끼리의 소통).

Apple 기준으로 "수집"은 기기 밖으로 나가 개발자가 볼 수 있게 되는 것이다. 그래서 기록장(기기와 사용자의 iCloud
개인 DB에만 있고 개발자가 못 본다), 기기 Keychain의 Apple 이메일, 기기 안의 기도제목 제안·번역은 수집이 아니다.
그룹 서버에 가는 것만 적는다.

모든 항목 공통: **사용자에게 연결됨: 예**, **추적: 아니요**, **목적: 앱 기능**.

| App Store 항목 | 무엇 | 비고 |
| --- | --- | --- |
| 연락처 정보 › 이름 | 그룹 표시 이름 | 실명이 아닐 수 있지만 사용자가 다른 사람에게 보이려고 넣는 이름이다 |
| 사용자 콘텐츠 › 사진 또는 비디오 | 글·댓글 사진, 프로필 사진, 스티커 | |
| 사용자 콘텐츠 › 기타 사용자 콘텐츠 | 기도제목·독후감·간증, 댓글, 반응, 신고 | |
| 식별자 › 사용자 ID | Apple 로그인 `sub`, 서버 사용자 ID | |
| 식별자 › 기기 ID | 설치 ID, APNs 기기 토큰 | |
| 사용 데이터 › 제품 상호 작용 | 그룹별 읽은 시각 | 안 읽은 글 수용. 적게 적는 것보다 많이 적는 쪽이 안전하다 |

넣지 않는 것과 이유:

- **구입 항목:** 구독이 꺼져 있다(`SUBSCRIPTION_REQUIRED=false`, 구매 화면 없음). 구독을 켜는 버전에서
  "구입 항목 › 구입 내역"(원 거래 ID, 상품, 상태)을 더한다.
- **이메일, 위치, 연락처, 건강, 금융, 검색 기록, 브라우징 기록:** 서버로 보내지 않는다. 시간대·언어는 Daily
  Report 시각과 알림 문구에만 쓰는 설정값이라 위치로 보지 않는다.
- **진단:** 충돌·성능 SDK가 없다. 서버 로그는 요청 처리용이며 수집 항목으로 보지 않는다.
