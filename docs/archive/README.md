# 문서 아카이브

이력용이다. 에이전트는 기본으로 읽지 않는다. 지금 지켜야 할 규칙과 열린 항목은 상위 `docs/`의 살아 있는 문서에 있다.

- `known-issues-history.md`: 정리 전 `known-issues.md` 원문(증상 이력, 진단, 배제한 가설).
- `pre-release-checklist-history.md`: 체크리스트에서 내린 완료 항목, superseded 빌드, 세션 로그.
- `visual-design-validation-history.md`: 1.0 (2)/(3) 시절 시각 검증 기록과 교체된 아이콘.
- `release-build25.md`, `app-review/`: 지난 릴리스 기록.
- `editor-refactoring-plan.md`: 2026-09-26 편집기 리팩토링 계획. 1차 구현 뒤 남은 단계는 `implementation-todo.md`로 옮겼다.
- `superpowers/`: 실행이 끝난 구현 계획과 설계 스펙.
- openspec의 끝난 변경은 `openspec/changes/archive/`에 있다.
