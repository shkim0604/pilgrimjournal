# 사용자 가이드

## Day One 내보내기

Day One에서 JSON 형식으로 데이터를 내보내 ZIP 파일을 만든다. Pilgrim Journal의
Mac 앱에서 `Day One 가져오기`를 선택한다.

1. ZIP을 선택한다.
2. 앱이 기록 수, 기간, 중복 예상 수와 미분류 수를 읽기 전용으로 분석한다.
3. 태그 또는 Day One 템플릿 규칙에 따라 제안된 유형을 확인한다.
4. 가져오기를 실행하고 성공·건너뜀·실패 결과를 확인한다.

같은 Day One UUID는 다시 가져와도 중복 생성하지 않는다. 현재 지원 계약은
Day One export version 1.0이다. 암호화 ZIP은 지원하지 않는다.

## iPhone 동기화

Mac과 iPhone에서 같은 Apple ID로 iCloud에 로그인하고 iCloud Drive를 켠다.
앱 내부의 별도 회원가입이나 Apple 로그인 버튼은 없다. 앱이 시스템 iCloud
상태를 자동으로 확인하며, iCloud를 사용할 수 없을 때도 local-only 기록은
계속 작성하고 검색할 수 있다.
로컬 저장은 즉시 완료되며 CloudKit 동기화는 네트워크 상태에 따라 나중에
완료될 수 있다. 동기화 중에도 로컬 기록을 읽고 편집할 수 있다.

## 앱 잠금

설정의 `앱 잠금`에서 이 기기 전용 비밀번호를 설정한다. 비밀번호는 6자
이상이며 즉시·1분·5분·15분 자동 잠금을 선택할 수 있다. 지원되는 기기에서는
Face ID 또는 Touch ID로 잠금을 해제하고 비밀번호를 fallback으로 사용할 수
있다.

잠금 비밀번호와 설정은 다른 기기로 동기화되지 않으므로 Mac과 iPhone에서
각각 설정한다. 비밀번호를 잊으면 기기 소유자 인증 후 재설정할 수 있다.
앱 잠금은 화면을 보호하며 CloudKit 데이터 자체를 비밀번호로 암호화하지는
않는다.

## 백업

Mac 설정에서 `전체 백업 내보내기`를 선택한다. 백업에는 기록, revision,
휴지통 tombstone, 분류 규칙과 첨부가 포함된다. 검색 인덱스는 포함되지 않으며
복원 후 다시 생성된다.

- 병합 복원: 현재 데이터에 없는 기록을 추가하고 충돌을 revision으로 남긴다.
- 교체 복원: 앱이 현재 상태의 안전 백업을 먼저 만든 뒤, 백업에 없는 현재
  기록을 휴지통으로 이동한다. 설정 화면에서 생성된 안전 백업 파일명을 확인할
  수 있다.

## 오류

- iCloud 계정 없음: 로컬 기능은 계속 사용할 수 있지만 기기 간 동기화는 멈춘다.
- iCloud 용량 부족: 로컬 원본을 삭제하지 않으며 공간 확보 후 재시도한다.
- 첨부 다운로드 실패: 기록 본문은 계속 열 수 있다.
- 검색 문제: 설정에서 검색 인덱스를 다시 만든다.
