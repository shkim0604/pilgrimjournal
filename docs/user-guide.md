# 사용자 가이드

앱을 사용하는 중에는 `설정`의 `도움말`에서 `앱 사용법`을 열어 핵심 기능의
안내를 오프라인으로 확인할 수 있다. iPhone에는 공통 기능만, Mac에는 Day One
가져오기와 백업·복원을 포함한 데이터 관리 안내도 함께 표시된다.

## 기록 작성과 편집

기록 목록의 `새 노트` 또는 도구 막대의 작성 버튼을 누른다. 기록 정보에서
기도노트, 성경공부, 독서노트, 일기, 메모 중 하나를 선택하고 제목과 본문을
작성하면 변경 내용이 자동으로 저장된다.

- 기도노트: 기도 상태와 응답일
- 성경공부: 성경 구절
- 독서노트: 책 제목과 저자
- 일기: 기분
- 메모: 공통 제목과 본문

기존 기록을 선택하면 제목, 본문, 날짜, 유형과 태그를 수정할 수 있다. 저장된
변경은 revision 이력에 남으며 이전 내용을 새 revision으로 복원할 수 있다.

## 첨부파일

편집 화면의 `파일`로 사진, 동영상, 오디오, PDF를 더하거나 `사진`으로 사진
보관함에서 여러 장을 한 번에 고를 수 있다. iPhone에서는 `촬영`으로 카메라를
바로 열어 찍은 사진을 첨부할 수 있다(카메라가 없는 기기·시뮬레이터에서는
버튼이 보이지 않는다). 첨부 상태는 목록에서 확인할 수 있다.

- 이 기기에 저장됨 / iCloud 업로드 대기 / iCloud 업로드 중 / iCloud에 저장됨
  / 다운로드 중 / 전송 실패
- 이 기기에 아직 없는 첨부는 `다운로드`를 눌러 먼저 받는다. CloudKit은
  특정 파일을 즉시 가져오도록 앱이 강제할 수 있는 방법을 제공하지 않아,
  일정 시간이 지나도 받아지지 않으면 자동으로 `재시도` 버튼으로 바뀐다 —
  동기화가 실제로 진행 중일 때는 "동기화 진행 중"으로 계속 기다린다.
- 이 기기에 있는 첨부는 눈 모양 아이콘으로 QuickLook(iOS) 또는 기본 앱
  (macOS)에서 바로 미리 보고, 저장 아이콘으로 다른 위치에 저장할 수 있다.

본문 편집 중에는 클립보드의 이미지를 그대로 붙여넣을 수 있다(⌘V/Ctrl+V 또는
꾹 눌러 붙여넣기). 붙여넣은 이미지는 첨부로 저장되고 본문에는 그 위치를
가리키는 텍스트가 남는데, 편집 화면에서는 원시 텍스트로 보이고 기록을
열람(보기) 화면으로 돌아오면 실제 이미지로 표시된다.

## 분류와 찾기

편집 화면에서 태그와 노트북을 지정한다. 설정의 `태그 및 Day One 분류 규칙`에서
태그 이름과 가져온 기록의 유형 분류 규칙을 관리할 수 있다.

기록 목록의 검색 칸에서는 제목, 본문과 태그를 검색한다. 검색이 예상대로 되지
않으면 설정에서 `검색 인덱스 다시 만들기`를 실행한다. 삭제한 기록은 바로
지워지지 않고 휴지통으로 이동하며, 설정의 데이터 관리에서 `휴지통 열기`를
선택해 복원할 수 있다.

휴지통 화면은 항상 다중 선택 상태다 — 기록을 하나 이상 골라 툴바의 `복원`
또는 `영구 삭제`를 누르거나, 툴바의 `휴지통 비우기`로 전체를 한 번에 지울 수
있다. 영구 삭제는 기록과 수정 이력, 첨부를 이 기기와
iCloud에서 완전히 지우며 되돌릴 수 없다. 다른 기록이 참조하지 않는 첨부
파일만 지워지고, 같은 내용을 공유하는 첨부는 보존된다. 아직 동기화되지 않은
다른 기기의 편집이 있으면 그 기기가 온라인 상태가 될 때 기록이 되살아날 수
있으므로, 다른 기기가 모두 동기화된 뒤 영구 삭제를 실행한다. Day One에서
가져온 기록을 영구 삭제하면 같은 원본으로 다시 가져올 수 있다 — 휴지통에만
있고 아직 영구 삭제하지 않은 기록은 계속 중복으로 취급된다.

## 유형 편집

사이드바의 `유형 편집`에서 기록 유형을 직접 관리한다. 새 유형 만들기, 이름·색·
아이콘 바꾸기, 끌어서 순서 바꾸기, 삭제를 할 수 있다. 미분류는 바꾸거나 지울 수
없다.

유형을 삭제하면 그 유형의 기록을 옮길 유형을 고른다(기본값은 미분류). 기록은
삭제되지 않고 옮겨지며, 기도노트처럼 전용 입력칸이 있던 유형은 입력한 값이 본문
끝에 글로 덧붙는다. 삭제한 기본 유형은 같은 화면에서 되살릴 수 있다. 이미 옮긴
기록은 되돌아가지 않는다. 직접 만든 유형은 되살릴 수 없다.

유형 구성은 iCloud로 모든 기기에 동기화된다. 유형 편집을 쓰기 전에 모든 기기를
이 버전 이상으로 업데이트한다.

## Day One 내보내기

Day One에서 JSON 형식으로 데이터를 내보내 ZIP 파일을 만든다. Pilgrim Journal의
Mac 설정에서 `Day One 가져오기…`를 선택한다.

1. ZIP을 선택한다.
2. 앱이 기록 수, 기간, 중복 예상 수와 미분류 수를 읽기 전용으로 분석한다.
3. 태그 또는 Day One 템플릿 규칙에 따라 제안된 유형을 확인한다.
4. 가져오기를 실행하고 성공·건너뜀·실패 결과를 확인한다.

같은 Day One UUID는 다시 가져와도 중복 생성하지 않는다. 현재 지원 계약은
Day One export version 1.0이다. 암호화 ZIP은 지원하지 않는다.

## Mac과 iPhone 동기화

Apple 로그인은 앱 화면 접근에 사용하고, 기록 동기화에는 별도로 기기의 시스템
iCloud 개인 데이터베이스를 사용한다. Mac과 iPhone에서 같은 Apple 사용자로
앱에 로그인하고 같은 iCloud 계정을 사용한다. 앱이 시스템 iCloud 상태를 자동으로
확인하며, iCloud를 사용할 수 없을 때도 local-only 기록은 계속 작성하고 검색할
수 있다.
로컬 저장은 즉시 완료되며 CloudKit 동기화는 네트워크 상태에 따라 나중에
완료될 수 있다. 동기화 중에도 로컬 기록을 읽고 편집할 수 있다.

## 앱 잠금

설정의 `앱 잠금`에서 이 기기 전용 비밀번호를 설정한다. 비밀번호는 6자
이상이며 즉시·1분·5분·15분 자동 잠금을 선택할 수 있다. 지원되는 기기에서는
Face ID 또는 Touch ID로 잠금을 해제하고 비밀번호를 fallback으로 사용할 수
있다.

잠금 비밀번호와 설정은 다른 기기로 동기화되지 않으므로 Mac과 iPhone에서
각각 설정한다. 비밀번호를 잊으면 기기 소유자 인증 후 재설정할 수 있다.
앱 잠금은 화면을 보호하며 CloudKit 데이터 자체를 비밀번호로 암호화하지는
않는다.

## 백업

Mac 설정에서 `전체 백업 내보내기…`를 선택한다. 백업에는 기록, revision,
휴지통 tombstone, 분류 규칙과 첨부가 포함된다. 검색 인덱스는 포함되지 않으며
복원 후 다시 생성된다.

- 병합 복원: 현재 데이터에 없는 기록을 추가하고 충돌을 revision으로 남긴다.
- 교체 복원: 앱이 현재 상태의 안전 백업을 먼저 만든 뒤, 백업에 없는 현재
  기록을 휴지통으로 이동한다. 설정 화면에서 생성된 안전 백업 파일명을 확인할
  수 있다.

영구 삭제한 기록은 그 이후에 만든 백업에는 포함되지 않는다. 다만 영구 삭제
이전 시점에 만든 백업을 교체 복원으로 되돌리면 그 기록이 휴지통이 아니라
타임라인으로 다시 나타난다 — 백업은 삭제 당시의 상태를 그대로 담고 있기
때문이다.

## 오류

- iCloud 계정 없음: 로컬 기능은 계속 사용할 수 있지만 기기 간 동기화는 멈춘다.
- iCloud 용량 부족: 로컬 원본을 삭제하지 않으며 공간 확보 후 재시도한다.
- 첨부 다운로드 실패: 기록 본문은 계속 열 수 있다.
- 검색 문제: 설정에서 검색 인덱스를 다시 만든다.
